### Vérification des mises à jour

L’application essaie ces routes successivement jusqu’à recevoir une réponse exploitable :

| Ordre | Route |
|---:|---|
| 1 | `GET /api/harmonix/apps/v2/releases` |
| 2 | `GET /api/harmonix/apps/v2/version` |
| 3 | `GET /api/harmonix/apps/releases` |
| 4 | `GET /api/harmonix/apps/version` |

Query commune :

```text
platform=android|windows|macos
app_version={version}+{build}
```

Si `download_url` est absent de la réponse, le téléchargement utilise :

```text
GET /harmonix/download/{platform}
```

### Sessions Rift / Sync

L’application appelle d’abord `/rift/`. Sur un `404` ou `405`, elle retente automatiquement la même route sous `/sync/`.

| Méthode | Route principale | Fallback |
|---|---|---|
| `POST` | `/api/harmonix/apps/v2/rift/sessions` | `/api/harmonix/apps/v2/sync/sessions` |
| `GET` | `/api/harmonix/apps/v2/rift/sessions/{sessionId}` | `/api/harmonix/apps/v2/sync/sessions/{sessionId}` |
| `POST` | `/api/harmonix/apps/v2/rift/sessions/{sessionId}/join` | `/api/harmonix/apps/v2/sync/sessions/{sessionId}/join` |
| `PATCH` | `/api/harmonix/apps/v2/rift/sessions/{sessionId}/state` | `/api/harmonix/apps/v2/sync/sessions/{sessionId}/state` |
| `DELETE` | `/api/harmonix/apps/v2/rift/sessions/{sessionId}` | `/api/harmonix/apps/v2/sync/sessions/{sessionId}` |

À noter : le `GET` d’une session est implémenté mais je n’ai trouvé aucun appel actif dans l’interface actuelle.

### Contraintes importantes pour Sonora/Kyros

- Toutes les routes, sauf potentiellement le login initial, reçoivent `Authorization: Bearer {token}`.
- Les réponses `/api/harmonix/apps...` peuvent suivre l’enveloppe `{ "ok": true, "data": ... }` : l’application extrait automatiquement `data`.
- Les pistes acceptent plusieurs conventions : `id` ou `track_id`, `title` ou `name`, `artist` ou `author`, `coverUrl` ou `cover_url`, `streamUrl` ou `stream_url`.
- `streamUrl` et `coverUrl` peuvent être des URL absolues ou des chemins relatifs fournis directement par Sonora/Kyros.
- `PUT /theme`, `/health`, les routes debug et `/catalog/albums` figurent dans d’anciens documents, mais ne sont pas appelés par le code actuel.
- Aucun WebSocket métier n’est utilisé.
